# UI (리소스팩·HUD·메뉴)

모드 없이 바닐라 클라이언트로 동작한다. 서버가 UI 리소스팩을 보내고, 그 안의 글꼴 글리프로 HUD와 메뉴 배경을 그린다.

## 구성

- **리소스팩**
  - 원본은 `src/main/resourcepack`이다. 그림·폰트·모델은 `scripts/gen-art.py`가 코드로 그린다. 외부 이미지는 쓰지 않는다.
  - 빌드할 때 재현 가능한 zip으로 묶는다. 내용이 같으면 SHA-1도 같다. 이 zip은 플러그인 jar 안에 `resourcepack.zip`으로 들어간다.
  - 서버는 `ResourcePackService`로 내장 HTTP(`config.yml`의 `resource-pack.port`, 기본 25580)에서 팩을 연다. 접속한 플레이어에게 `http://<접속에 쓴 주소>:25580/pack/<sha1>.zip`과 SHA-1을 보낸다.
  - 기본값은 필수(`required: true`)다. 거절하면 클라이언트 접속이 끊긴다.
  - 외부에 공개할 때는 `public-host`를 지정한다.
- **HUD** (`HudLayout`, `HudRenderer`)
  - 액션바 한 줄에 HP 바, 레벨 원, MP 바를 그리고 4틱마다 다시 보낸다.
  - 줄의 총 진행폭을 핫바 폭(182)에 맞춰 바가 항상 같은 자리에 있게 한다. 높이는 폰트 ascent로 내려 바닐라 하트·배고픔 줄 자리에 둔다.
  - 미사용 포인트(`+N`)는 레벨 원 위에 표시한다.
  - 짧은 알림(치명타, 보상 잠금)은 2초 동안 HUD와 함께 보인다.
- **바닐라 HUD 숨김**
  - 하트·방어구·배고픔·경험치바 스프라이트를 투명 그림으로 바꾼다.
  - 보이지 않는 수치가 게임에 영향을 주지 않도록 배고픔은 항상 가득, 바닐라 경험치는 0으로 둔다(`VanillaHudListener`, `HudTask`).
- **메뉴** (`MenuService`, `RpgMenu`)
  - 6줄 상자 화면을 쓴다. 제목에 176x222 배경 글리프를 넣어 상자 그림을 덮는다.
  - 메뉴가 열려 있는 동안 모든 클릭과 드래그를 취소하고, 등록된 버튼만 실행한다.
  - 메인: 장비, 스탯, 보상 수령(대기 보상 수 표시)
  - 스탯: 7종. 클릭은 +1, 쉬프트 클릭은 상한·남은 포인트 안에서 +10. 능력치 요약이 함께 나온다.
  - 장비: 착용 방어구 4칸과 주 무기·보조 손을 보여준다. 보기 전용이라 복사본만 표시한다.
  - 열기: `/rpg`(별칭 `/menu`) 또는 웅크린 채 F(손 바꾸기). 기존 `/rpg stats|alloc|claim`도 그대로 쓸 수 있다.

## 그림 수정

```bash
python3 scripts/gen-art.py       # src/main/resourcepack 다시 생성
python3 scripts/preview-art.py   # build/art-preview/*.png 확대 미리보기
./gradlew build                  # ResourcePackTest: 폰트·텍스처·모델 구조와 코드 상수(Glyphs, IconModels) 대조
```

글리프 코드포인트·크기·슬롯 위치를 바꾸면 `ui/Glyphs`, `ui/IconModels`, `MenuService`의 위치 상수도 함께 바꿔야 한다. 어긋나면 `ResourcePackTest`가 잡는다.

## 검증

`EULA_ACCEPTED=true scripts/e2e.sh ui` (`e2e/ui.mjs`)로 다음을 확인한다.

- 리소스팩
  - 접속하면 필수 리소스팩 요청이 온다.
  - 주소에서 받은 파일의 SHA-1이 요청 해시, 서버 로그와 같다.
  - 다른 경로는 404다.
- HUD
  - 액션바에 HP·MP 바와 레벨 원 글리프 3개, 숫자가 들어 있다.
  - 경험치 구슬이나 `xp` 명령을 써도 바닐라 레벨·배고픔이 고정된다.
- 메뉴
  - `/rpg`로 연 메인 메뉴에서 스탯 화면으로 넘어간다.
  - + 클릭, 쉬프트 클릭, 상한 초과, 오른쪽 열 버튼이 모두 맞게 반영된다.
  - 아이콘을 집을 수 없다.
  - 장비 화면에 주 무기가 표시되고, 장비가 복제되지 않는다.
  - 보상 버튼이 대기 보상 수를 보여 주고, 누르면 수령된다.
  - Shift+F로 메뉴가 열린다.

화면에 실제로 어떻게 보이는지(픽셀 정렬)는 클라이언트에서 직접 확인해야 한다.
