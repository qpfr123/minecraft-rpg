# 슬라이스 2 — 던전 인스턴스와 사망 페널티

기준: 2026-10-03 결정(사망 페널티: 보존, 다음 작업: 던전). 설계 원본: [design.md](design.md)의 "솔로 플레이와 1:1 상호작용" 3단계.

## 결정 사항

- **사망 페널티: 보존.** 죽어도 RPG 장비·소모품은 인벤토리에 그대로 남는다. 바닐라 아이템은 바닐라 규칙대로 떨어진다. EXP·레벨은 잃지 않는다.
- 던전은 입장 단위로 템플릿 월드를 복제한 인스턴스다. 몹·블록·AI·전리품은 인스턴스 월드 안에서만 존재한다.

## 구현 범위

| 항목 | 내용 |
| --- | --- |
| 던전 1종 | `crypt`(지하 납골당). 직선 회랑 65칸, 구울 5·해골 궁수 2, 보스 `crypt_warden`(HP 1200, ATK 20, DEF 15%). 최대 4명 |
| 템플릿 | 서버 시작 시 `rpg_tpl_crypt` 월드를 코드로 만들어 저장·언로드한다. 배치 버전(`layoutVersion`)이 바뀌면 다시 만든다. 인스턴스는 언로드된 템플릿 폴더를 복사해 만든다(실행 중인 월드는 복사하지 않음) |
| 입장 | `/dungeon enter crypt`. 파티가 있으면 리더만 입장시킬 수 있고, 접속 중인 파티원 전원이 함께 들어간다. 멤버는 입장 때 확정된다 |
| 귀환 위치 | 텔레포트 전에 DB(`dungeon_sessions`)에 먼저 기록한다. 서버가 꺼져도 다음 접속 때 원래 위치로 돌려보낸다 |
| 클리어 | 보스 처치 시 인스턴스 안에 있는 멤버마다 클리어 보상 1건(`dungeon:<인스턴스>:clear`, EXP 400 + 강장제, 투구 30%). 슬라이스 1의 보상 원장·수령 경로를 그대로 쓴다. 보스 처치 보상은 기존 기여 5% 규칙 |
| 사망 | 던전 안에서 죽으면 같은 인스턴스 입구에서 리스폰한다 |
| 종료 | 클리어 후 귀환 지연(기본 30초), 유휴(안에 접속 중인 멤버 없음, 기본 120초), 멤버 전원 퇴장 → 귀환·월드 언로드(저장 안 함)·폴더 삭제 |
| 상한 | 동시 인스턴스 기본 4개. 준비 중·정리 중인 인스턴스도 셈한다 |
| 재시작 복구 | 서버 시작 시 남은 `rpg_inst_*` 폴더를 지운다. 입장 기록이 남은 플레이어는 접속할 때 원래 위치로 돌려보낸다 |
| 파티 | `/party invite <플레이어>`, `/party accept`, `/party leave`, `/party list`. 최대 4명. 메모리 전용이라 접속을 끊거나 서버를 재시작하면 빠진다 |
| 관리자 | `/rpgadmin dungeon list | cap <n> | idle <초> | exitdelay <초>` |

## 통과 조건과 결과 (2026-10-03)

- 단위 테스트: 인스턴스 상한·유휴·클리어·멤버 고정(`InstanceTrackerTest`), 파티 초대·수락·리더 승계·해산·인원 상한(`PartyServiceTest`)
- 봇 E2E 23개: `EULA_ACCEPTED=true scripts/e2e.sh dungeon`
  1. 사망 시 RPG 장비는 남고 바닐라 아이템은 떨어진다
  2. 솔로 입장 시 인스턴스가 생기고 입구로 이동한다. 몹은 구울 5, 해골 궁수 2, 보스 1이다
  3. 상한 1에서 두 번째 인스턴스는 거절되고, 상한 2에서는 다른 월드로 생성된다
  4. 한 인스턴스의 몹을 없애도 다른 인스턴스에는 영향이 없다
  5. 퇴장하면 원래 위치로 돌아가고, 빈 인스턴스는 정리된다(폴더 삭제)
  6. 유휴 시간 전에 재접속하면 던전 안으로 돌아간다. 유휴 시간을 넘기면 인스턴스가 정리되고, 재접속 시 원래 위치로 돌아간다
  7. 파티원(리더 아님)은 입장시킬 수 없다. 파티 입장 시 두 사람이 같은 인스턴스에 들어간다. 던전 안에서 죽으면 입구에서 리스폰한다. 파티를 떠나도 멤버는 유지된다
  8. 보스를 처치하면 멤버별 클리어 보상이 1건씩 생기고, 귀환 지연 뒤 두 사람 모두 원래 위치로 돌아간다. 인스턴스도 정리된다
  9. 던전 안에서 서버를 강제 종료(SIGKILL)한 뒤 재시작하면 남은 폴더가 삭제되고, 접속 시 원래 위치로 돌아간다

## 한계와 다음 후보

- 던전은 1종, 배치는 코드로 만든 단순 회랑이다. 실제 맵 제작(스키매틱 불러오기)은 다음 단계다.
- 파티는 메모리 전용이다. 파티 보상 분배(일반 몹은 지금도 첫 타격자 소유)는 아직 정하지 않았다.
- 인스턴스 안의 보스 기여 기록도 메모리 전용이다. 클리어 보상은 원장으로 한 번만 생성된다.
- 성능 합격선(동시 인스턴스 수별 MSPT·월드 생성 시간)은 목표 동시 접속 규모를 정할 때 측정한다.
